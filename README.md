# ayoma releases

Download the launcher:

https://github.com/bodyqulll/ayoma-releases/releases/latest/download/ayoma-launcher.exe

Run `ayoma-launcher.exe`. It checks this repository for the latest version, verifies the package SHA-256, installs to `%LOCALAPPDATA%\ayoma\app`, and starts ayoma. Your license is stored outside the app folder and survives updates.

## Requirements

- Windows 10/11 x64
- Administrator rights for the loader
- Secure Boot disabled + test signing enabled for the kernel driver (see the release notes)

## Licensing

Access requires a KeyAuth license key bound to your PC. This repository only distributes binaries; the source stays private.
